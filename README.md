# sprout

App web instalable para seguir una rutina de calistenia: sesiones guiadas con ejercicios animados, series y descansos, resumen tipo RPG, historial, estadísticas y logros.

Tus datos se guardan solo en tu teléfono (almacenamiento local del navegador).

**Instalar en iPhone:** abre la página en Safari, toca Compartir y luego "Añadir a pantalla de inicio".

Usa [morphdom](https://github.com/patrick-steele-idem/morphdom) (MIT) para actualizar la pantalla.
