# keystone

App web instalable para entrenamiento, comida, hábitos y salud: sesiones guiadas con ejercicios animados, registro de comidas con análisis de fotos por IA, hábitos diarios, agua, recordatorios y un perfil de salud con nota por área.

Tus datos se guardan solo en tu teléfono (almacenamiento local del navegador).

**Instalar en iPhone:** abre la página en Safari, toca Compartir y luego "Añadir a pantalla de inicio".

Usa [morphdom](https://github.com/patrick-steele-idem/morphdom) (MIT) y la tipografía [Geist](https://github.com/vercel/geist-font) (OFL).
